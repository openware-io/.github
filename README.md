# .github

openware-io 的组织级社区健康文件仓库。

GitHub 会自动将本仓库中的 `LICENSE`、`CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`SECURITY.md` 应用到组织内所有未自带对应文件的公开仓库。

## 组织文档入口

| 文档 | 用途 |
| --- | --- |
| [profile/README.md](profile/README.md) | GitHub 组织主页：两大工程、仓库地图与快速入口 |
| [CONTRIBUTING.md](CONTRIBUTING.md) | 跨仓库贡献流程与提交约定 |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | 社区行为准则 |
| [SECURITY.md](SECURITY.md) | 漏洞私下报告渠道与安全约定 |

## 两大工程

组织主页按两个长期工程组织：

- **Open IM**：开源即时通讯 + 多租户 SaaS 一体化平台；
- **GreenPass**：软件工程测试治理平台。

各工程的详细仓库、技术栈和文档入口见 [组织主页](profile/README.md)。
